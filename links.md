### Palette (pulled from page CSS)

| Role | Hex | Notes |
|------|-----|-------|
| Primary olive | `#565c46` | most-used color; headings, buttons |
| Dark olive | `#444d30` | darker accent |
| Deep olive | `#323727` | body text |
| Sage | `#9aa288` | soft accent, decorative only (low contrast on cream) |
| Greige | `#dbd4ca` | borders, dividers, panels |
| Cream | `#fcf5ea` | page background |
| Ivory | `#fffaf3` | cards, inputs |
| Peach | `#efd5bc` | rare highlight |

### Fonts (from page font files)

- Headings: **The Seasons** (paid) — site uses free stand-in **Cormorant Garamond**
- Script: **Pinyon Script** (Google Fonts)
- Body: template uses **Arimo**; we switched to **Jost** (Google Fonts) for a cleaner look
