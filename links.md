### Fonts (from page font files)

- Headings: **The Seasons** (paid) — site uses free stand-in **Cormorant Garamond**
- Display: now **GNU FreeSerif** in wide-spaced capitals, matching `info/Screenshot 2026-11-04 233555.png` (names stacked JEREMIE / & / MICHELLE). Self-hosted at `fonts/FreeSerif.woff`, unmodified from ftp.gnu.org/gnu/freefont (GPL with font exception; keep the file unmodified so its embedded license stays valid). 1.7 MB because it covers many scripts. Earlier tries: Cinzel, Sevillana (too playful). Before that it was **Alex Brush**, the closest free match to **Amoresa**, the script on the Kevin & Chiara Canva site. Amoresa is a paid font licensed through Canva, so its file can't be reused here. That site's other display font, **Hello Paris**, is a thin all-caps serif, not cursive.
- Body: template uses **Arimo**; we switched to **Jost** (Google Fonts) for a cleaner look
